# IBM Carbon Design System

Made by `tools/carbon-fetch.sh 2.68.0`; do not edit these files, run the
script again.

- `*.js`: IBM's ready files of `@carbon/web-components` 2.68.0, from
  IBM's CDN, unchanged: the components
  ui-shell, button, icon-button, tag, notification, content-switcher, toggle-tip, text-input, password-input, textarea, number-input, select, checkbox, toggle, modal, progress-bar, inline-loading, skeleton-text, code-snippet, copy-button, breadcrumb, file-uploader, tooltip, pagination,
  and the shared files they load.
- `themes.css`: the themes g10 (light) and g100 (dark) of `@carbon/styles`
  1.120.0.
- `icons.svg`: icons of `@carbon/icons` 11.92.0; `NAME-g10.svg` and
  `NAME-g100.svg`: chevron--down in each theme's icon colour.

All three are Copyright IBM Corp. under the Apache License 2.0, in
